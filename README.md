# Material Web Messenger

Современное веб-приложение для обмена сообщениями, созданное в строгом соответствии со спецификацией **Google Material Design 3 (Material You)**. Проект сочетает динамическую тональную палитру, адаптивную многопанельную компоновку, тактильные слои состояний и продвинутую систему интерактивных чатов.

---

## 🌟 Ключевые возможности

### 🎨 Дизайн-система Material Design 3 (Material You)
* **Тональная палитра**: Точная реализация базовой палитры M3 (`primary`, `on-primary`, `primary-container`, `secondary`, `surface`, `surface-container-*`, `outline`).
* **Динамические темы (Dynamic Color)**: Мгновенное переключение акцентных палитр в реальном времени:
  * 💜 **Material Purple** (`#6750A4`) — классический акцент Material You
  * 🌊 **Ocean Teal** (`#00677D`) — морской бирюзовый
  * 🌿 **Botanical Sage** (`#3B6939`) — ботанический шалфей
  * 🌅 **Sunset Amber** (`#855318`) — янтарный закат
* **Уровни возвышения (Elevation Tiers)**:
  * **Level 0**: Плоский базовый холст (`surface`)
  * **Level 1**: Входящие сообщения, поисковая строка в покое, карточки (`surface-container-low`)
  * **Level 2**: Активные поисковые строки, фокусы
  * **Level 3**: Плавающие кнопки FAB в покое, выпадающие меню
  * **Level 4**: FAB при наведении/нажатии
  * **Level 5**: Модальные окна и экраны звонков
* **Типографика**: Переменный шрифт **Roboto Flex** с оптимизированными масштабами Headline, Title, Body и Label.

---

### 📱 Адаптивные экраны (Responsive Multi-Pane Layout)
Интерфейс динамически перестраивается под ширину экрана согласно гайдлайнам Material 3 (также доступен переключатель симуляции в шапке приложения):

1. **Mobile (< 600dp)**:
   * Однопанельный стек (Single-pane stack view)
   * Нижняя панель навигации (**Bottom Navigation Bar**, 80px) с индикаторами-пилюлями (32×64px)
   * Полноэкранный просмотр активного чата с кнопкой «Назад»
   * Плавающая кнопка действия FAB (56×56dp)
2. **Tablet (600dp – 839dp)**:
   * Двухпанельный гибкий интерфейс
   * Компактная боковая рельса (**Navigation Rail**, 80px)
   * Мастер-список чатов шириной 320dp и динамическая область переписки
3. **Desktop (≥ 840dp)**:
   * Трехпанельный холст
   * Раскрывающаяся навигационная рельса (80px / 256px)
   * Список диалогов фиксированной ширины (360–380dp)
   * Динамическое окно переписки
   * Сворачиваемая правая шторка с деталями чата (**Details Drawer**, 360dp)

### 💬 Интерактивные функции сообщений
* **Асимметричные пузыри сообщений (Chat Bubbles)**:
  * Исходящие: фон `primary`, белый текст, закругления `rounded-2xl` с острым нижним правым углом (`4px`).
  * Входящие: фон `surface-container`, темный текст, острый нижний левый угол (`4px`).
  * Последовательные сообщения от одного автора сглаживаются в равномерный радиус 16px.
* **Голосовые заметки (Voice Notes)**:
  * Симуляция записи голоса с пульсирующим индикатором и таймером.
  * Интерактивный плеер с анимированной визуализацией звуковой волны (waveform), прогресс-баром и длительностью.
* **Медиа и файлы**:
  * Просмотр изображений и модальное окно полноэкранного зума.
  * Прикрепление и скачивание документов/спецификаций.
* **Цитирование и ответы**:
  * Ответ на конкретное сообщение со всплывающей плашкой цитаты.
* **Реакции и эмодзи**:
  * Быстрые реакции на сообщения (❤️, 👍, 🔥, 🎉, 😂) со счетчиками пользователей.
  * Палитра стикеров и эмодзи.
* **Симуляция ответов собеседника**:
  * Реалистичный индикатор набора текста (*«Maya Lin is typing...»*) и автоматические контекстные ответы.
* **Звонки (Voice & Video Calls)**:
  * Модальное окно голосового и видеовызова (M3 Level 5 elevation) с анимированными звуковыми волнами, управлением камерой, микрофоном и длительностью.
* **Шторка с деталями**:
  * Профиль контакта/группы, список медиафайлов, документов, ссылок, список участников и настройки уведомлений.

## 🛠 Технологический стек

* **Фреймворк**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Сборщик**: [Vite 8](https://vitejs.dev/)
* **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com/) с пользовательскими переменными M3
* **Иконки**: [Lucide React](https://lucide.dev/)
* **Анимации**: [Motion](https://motion.dev/)
* **Шрифты**: Google Fonts **Roboto Flex**

## 🚀 Запуск и сборка

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Сервер запустится по адресу: `http://localhost:3000`

### Сборка проекта
```bash
npm run build
```
